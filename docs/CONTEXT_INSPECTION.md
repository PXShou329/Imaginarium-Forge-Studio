# 生成紀錄與隱私

作品、角色、提示詞與生成紀錄預設保存在本機 SQLite 資料庫。資料庫與備份可能含完整原稿，請作為私人作品保管。

## 生成時保存什麼

故事生成與修訂會保存輸入版本、生成選項、狀態及結果。預設也會保存實際送給文字生成服務的 `system` 與 `user` 訊息，讓 Context Inspector 能檢查當次上下文。

訊息可能含角色設定、世界規則、場景規劃、指令及修訂來源全文。成功、失敗、取消或程序中斷的生成紀錄都可能留存這些輸入。

## 停止保存未來訊息原文

若不需要保存生成請求的完整原文，在專案根目錄 `.env` 設定：

```dotenv
IMF_STORE_RENDERED_GENERATION_MESSAGES=false
```

儲存後完整停止並重新啟動應用程式。這只影響之後的生成，既有紀錄與備份保持原樣。停用後仍會保存輸入版本、選項、訊息的 SHA-256 與位元組大小，以及生成結果或部分草稿。

## Context Inspector 的顯示

Inspector 會區分：

| 狀態 | 含義 |
| --- | --- |
| 當時實際送出的訊息（已儲存） | 原文已保存，且通過 SHA-256 與位元組大小驗證。 |
| 由保存的輸入快照重建，摘要相符 | 原文未保存；依輸入版本重建的內容與當時摘要相符。 |
| 無法逐位元重現 | 必要來源缺失或目前內容整理方式無法重現原始訊息；顯示的候選不能當成當時原文。 |
| 原文完整性驗證失敗 | 保存內容缺失或摘要不符；請保留警告並檢查資料庫與備份。 |

原文未保存時，程式更新、來源版本缺失或文字格式差異都可能影響重建。摘要不能還原原文，Inspector 也不能重建模型內部狀態或隱藏推理。

## 網路與金鑰

內建離線素材無須連網。預設 Ollama 端點為本機 `http://localhost:11434`。使用 OpenAI 或其他允許的遠端端點時，生成所需內容會送往該服務；保存、計費與刪除政策由服務提供者管理。

AI Key 請使用介面提供的工作階段設定或作業系統憑證庫，不要寫進 `.env`、原始碼、備份說明或公開問題回報。分享截圖及診斷資料前，請檢查是否含原稿或私密資訊。

## 備份與作品封存

備份會保存當時資料庫的故事、草稿、提示詞與生成紀錄，並非去識別化資料。還原時另建的安全備份也需妥善保管。

作品封存只是狀態變更，不會刪除內容。所有作品共用同一份資料庫；程式沒有單一作品永久刪除介面。若要清空全部本機作品，請先確認備份需求，完整停止應用程式後，再處理設定所指向的精確資料庫與備份位置。預設資料目錄為 `data/`，可由 `IMF_DATA_DIR` 調整。

刪除目前資料庫不會同時刪除其他備份、匯出檔或遠端服務紀錄。
