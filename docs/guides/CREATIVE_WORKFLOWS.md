# Imaginarium Forge 創作工作流指南

Imaginarium Forge 可以從完全空白、半個念頭，或你已經寫好的內容開始。離線隨機、Ollama
與 OpenAI 產生的內容都先放進編輯器或候選區；你可以修改、比較與保存，再明確決定是否接受
為正式版本。

## 先認識新版介面

- **左側導覽**依首頁、自由創作、我的書架、創作工作室、AI 與工具、設定與說明分組。
- **上方工具列**提供返回、上一頁、下一頁、工作頁搜尋、快速建立與目前環境狀態。
- **手機版**使用首頁、創作、書架、工作室與更多五個底部入口；左上角按鈕可重新開啟完整導覽。
- 圖片提示詞草稿若有未保存內容，應用內導覽仍會先詢問要保存、保留復原內容，或繼續編輯。

工作頁搜尋只搜尋應用程式功能，不會搜尋或上傳你的故事內容。

## 不開作品也能開始

展開「自由創作」，可直接使用以下工具：

- **自由創作箱**：集中整理已正式保存、尚未綁定作品的草稿。
- **懶人標籤生成器**：用繁體中文標籤組合角色、背景與 Negative Prompt。
- **故事片段草稿**：先寫敘事、對白、開場或單一場景。
- **角色與故事草稿**：整理人物背景、個人故事與圖片 Prompt。
- **世界種子草稿**：保存舞台、規則、地點、社會、衝突與主題。
- **圖片提示詞草稿**：保存、精修與恢復 character／background Prompt。

自由草稿不會自動變成正式角色、Story Scene、Story Bible 或 Canon；是否收入作品，始終由你
決定。

### 用繁中標籤製作圖片 Prompt

1. 選擇要做角色、背景，或角色加背景。
2. 角色可選成年女性或成年男性，再依身分、身材、臉部、髮型、服裝、動作與畫面風格挑選。
3. 想保留已選內容時用「只補空白」；想換一套方向時用「全部重新隨機」。
4. 隨機後仍可逐項增減，英文 Prompt 會依目前選擇立即更新。
5. 檢查下方的完整英文 Prompt，再複製、下載 TXT，或送到圖片提示詞草稿繼續精修。

開啟 18+ 成人模式前，必須先完成成年資格確認。成人模式的完整隨機會同時涵蓋成人身體細節
與成人動作／表情，但手動限定的「其他（18+）」不會被隨機加入。不相容的狀態、服裝或活動
會被安全規則拒絕；系統不會為了湊出結果而偷偷覆寫你已經選好的內容。

### 先寫世界種子或故事片段

你可以完全手寫，也可以先填幾格後按「只補空白」，或用「全部重抽」換一套內建離線素材。
這些按鈕只更新目前編輯器，不呼叫模型、不自動保存，也不會建立正式 Canon。

世界種子與故事片段目前採明確保存；離開前請按保存。封存會保留內容與唯讀查閱，不等於刪除。

### 圖片提示詞草稿的復原保護

圖片提示詞草稿有額外的本機復原保護。輸入內容改變後，畫面會顯示尚未保存、正在保存或已保存
狀態。若其他視窗先更新同一草稿，系統不會強制覆寫較新的版本，而會讓你另存成新草稿。

重新啟動後若偵測到可恢復內容，頂端會提供恢復、稍後處理或明確放棄。這套自動保存目前只
適用於圖片提示詞草稿，不是全站 Undo／Redo。

## 建立並打開一本作品

在「我的書架」建立作品，或打開既有作品。每一本書都是獨立的故事宇宙；書名、簡介、角色、
世界、故事、風格與 Prompt 版本都以該作品為範圍。

封存作品不會刪除內容。若書架仍是空的，首頁會顯示建立第一本書或先自由創作的入口，不會填入
虛構作品、進度或活動。

## 從一點線索長出完整候選

打開作品後，進入「創作工作室 → 完整創作與精修」或「靈感生成」。你可以選擇：

- 整本都幫我想；
- 只做一個角色；
- 先長出世界；
- 找到故事主線。

作品名、角色名、線索與調整方向都可以只填一部分。使用「只補空白」會保留已有內容；使用
「全部換一版」才會重新產生可替換的部分。候選可以比較、局部重抽、混合與鎖定，但在你帶到
精修桌並明確保存前，不會寫成正式作品內容。

成人暗示或成人露骨內容只會在具備可驗證成年角色的流程中提供，且必須由你確認年齡與成人
呈現。少任何一項確認就不建立候選。

## 在 Story Studio 寫作

Story Studio 把作品需求、Story Bible、大綱、章節、場景、生成、修訂、記憶、上下文、匯出與
劇本改編放在同一個寫作工作區。建議順序如下：

1. 建立或選擇 Story Requirement。
2. 整理 Story Bible 與世界規則。
3. 建立大綱、章節與 Scene Card。
4. 手寫、離線隨機，或請 Ollama／OpenAI 產生故事候選。
5. 編輯候選並保存新版本。
6. 確認內容後，再明確接受為正式版本。

後續生成只會使用符合規則、已接受且來源可驗證的上下文。Story Memory 也必須先提案，再由你
接受；生成完成不會自動把記憶寫入正式脈絡。

### 完整短篇與下一篇章

你可以提供簡易世界觀、短故事、大綱或結構，讓模型擴展成可編輯的完整短篇候選。進入同一
大綱的下一篇章時，系統會使用先前已接受且符合來源規則的摘要與角色脈絡；未接受內容不會被
當成正式前情。

### 劇本改編

劇本改編只從完整、已接受的小說 Scene 建立獨立候選與版本鏈。接受劇本不會改動原小說版本；
若小說來源已改變，舊劇本會被標示為需要建立後續版本，不會偷偷同步覆寫。

目前尚未提供 Shot List、Storyboard、Fountain 或完整影片 Prompt package。

## 管理角色、Canon 與風格

- **Canon Vault**顯示作品內真實存在的角色、Story Bible 與視覺風格概況，並提供前往正式編輯頁
  的入口。它不是尚未存在的泛用百科資料庫。
- **專案角色**可新增角色、保存基本資料、角色弧、Visual DNA 版本與服裝。
- **圖片風格**保存可重用的 Style Profile 與不可變版本。

新版本會保留歷史。畫面上的目前版本或已接受版本，是明確指標，不代表舊資料被覆寫。

## 在 Prompt Studio 建立正式 Prompt

Prompt Studio 會把場景來源、精確角色版本、服裝、視覺風格與本機 checkpoint 資訊組合成可
檢查的正式 Prompt：

1. 選擇或建立 Prompt Project。
2. 輸入繁中場景，檢查解析結果與不確定項目。
3. 選定精確角色／風格／服裝／checkpoint 版本。
4. 編譯並檢查警告、成人資格與來源是否過期。
5. 保存版本；需要正式使用時再明確接受。
6. 從已保存版本匯出 Markdown、JSON 或影片 Prompt bundle。

匯出不會呼叫 ComfyUI。請把 Prompt 帶到你自己的外部 ComfyUI 生成，再自行保存產物。

## 選擇離線、Ollama 或 OpenAI

### 離線隨機

使用內建繁中素材，不連網、不呼叫模型。適合先找方向，再自行編輯。離線動作只更新目前
編輯器或候選，不會自動保存或接受。

### Ollama

Ollama 必須由你自行安裝並啟動。若選擇的模型尚未存在，介面會先詢問是否下載；只有選「是」
才會要求 Ollama 下載，選「否」不會下載或生成。Imaginarium Forge 不會自行安裝或啟動 Ollama。

### OpenAI

在「AI 與工具 → AI 設定」輸入 API Key。你可以選擇只用於下一個動作，或在目前工作階段記住；
每次真正傳送內容前仍需要明確同意。

API Key 不會寫入 SQLite、`.env`、備份、Prompt、log、文件、Git 或匯出。使用 OpenAI 會把該次
請求所需內容傳到 OpenAI，並可能產生費用。若驗證、額度、速率、模型、逾時或連線有問題，
介面會顯示分類後的提示，但不會為排錯偷偷再送一次請求。

## 備份與搬移

在「設定與說明 → 設定與備份」建立備份。應用程式會以 SQLite online backup 方式納入目前
資料，並產生可驗證的 manifest。

搬到另一台電腦時，請保存備份檔與同名 manifest。不要直接複製仍在執行中的主資料庫，也不要
讓兩台電腦同時開啟位於 OneDrive、Dropbox、NAS 或網路磁碟的同一個 SQLite 檔案。

故事、Prompt、備份與匯出可能包含完整私人原稿或成人內容，請視為私密資料保管。

## 目前尚未提供

- 雲端同步、帳號、多人共編或兩台電腦自動合併；
- 通用 Canon Entry 百科 CRUD；
- Stable Story Block 編輯器、beat anchor 或媒體綁定；
- Story Fragment 一鍵轉成正式 Scene；
- 媒體收件匣、圖片／GIF／影片回填與圖文故事編排；
- Shot List、Storyboard、Fountain 與完整影片 Prompt package；
- 在專案內安裝、啟動或呼叫 ComfyUI。

沒有執行過的能力不會以假資料、假進度或假狀態顯示。
