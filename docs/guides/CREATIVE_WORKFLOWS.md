# 創作指南

Imaginarium Forge 可以從空白草稿、簡短線索或既有作品開始。候選內容由你編輯、保存與接受；生成完成不會自動改寫正式作品。

## 找到工作頁

左側導覽依首頁、自由創作、我的書架、創作工作室、AI 與工具、設定與說明分組。頂部提供主頁、搜尋、建立、翻譯與狀態入口；AI 設定從 **狀態** 進入。手機版可用底部入口切換分組。

工作頁搜尋用來找應用程式功能，不會搜尋或上傳故事內容。

## 自由草稿

不用建立作品，即可在 **自由創作** 使用：

- **故事片段草稿**：撰寫敘事、對白、開場或單一場景。
- **角色與故事草稿**：整理人物背景、個人故事與圖片 Prompt。
- **世界種子草稿**：保存舞台、規則、地點、社會、衝突與主題。
- **圖片提示詞草稿**：保存與精修角色或背景 Prompt。
- **自由創作箱**：整理已保存、尚未綁定作品的草稿。

內建離線靈感可補空白或換一套素材，不需模型。這些動作只更新編輯器，請確認後按保存。自由草稿不會自動變成作品的正式角色、場景或世界設定。

圖片提示詞草稿另提供本機復原保護與離頁提示。若其他視窗已更新同一草稿，可另存新草稿；重新啟動後若有可復原內容，會提供恢復入口。其他工作頁請依各頁保存按鈕操作。

## 懶人標籤生成器

1. 選擇角色、背景，或角色加背景。
2. 依身分類型挑選外觀、髮型、服裝、動作與畫面風格。
3. 用 **只補空白** 保留已選項目，或用 **全部重新隨機** 尋找新方向。
4. 逐項調整標籤，檢查下方即時更新的英文 Prompt。
5. 複製、下載 TXT，或送到圖片提示詞草稿繼續精修。

若組合矛盾，頁面會提示調整並保留上一個有效 Prompt。這個工具組合文字，不會直接生成圖片。

## 建立作品與整理角色

在 **我的書架** 建立或開啟作品。角色、世界、故事與提示詞版本以作品為範圍保存。封存作品會保留內容，可從封存區還原。

**專案角色**用來新增角色、保存基本資料、角色弧、外觀版本與服裝；**圖片風格**保存可重用的視覺風格。**Canon Vault**彙整作品內的角色、故事設定與視覺風格，並提供正式編輯入口。

**完整創作與精修**可從少量線索產生整本作品、角色、世界或故事主線候選。可以比較、混合、鎖定與局部重抽，確認後再帶到精修桌保存。

## 故事寫作

故事寫作工作區整合故事需求、故事聖經、大綱、章節、場景與草稿：

1. 建立故事需求與故事聖經，整理世界規則。
2. 建立大綱、章節與場景卡。
3. 手寫草稿，或選擇可用的 AI 服務產生候選。
4. 編輯、比較並保存版本。
5. 確認內容後接受版本，供後續續寫使用。

故事記憶先以提案呈現，接受後才進入正式脈絡。未接受的候選不會自動成為前情。

劇本改編從完整、已接受的小說場景建立獨立版本。接受劇本不會改動小說；小說來源變更時，介面會提示來源狀態。長篇生成需要已設定且可用的文字生成服務，內建離線素材適合尋找靈感。

## 正式提示詞工作台

1. 選擇或建立 Prompt Project。
2. 輸入繁中場景，檢查解析結果與待確認項目。
3. 選定角色、服裝、風格與 checkpoint 版本。
4. 編譯、檢查警告並保存版本。
5. 確認後接受版本，匯出 Markdown、JSON 或影片 Prompt 套件。

匯出只產生文字與結構資料。請在自己的外部圖片或影片工具中使用；程式不會送出 ComfyUI queue。

## AI 設定

頂部 **狀態 → AI 設定** 管理共用服務、模型與金鑰。

- **離線靈感**使用內建素材，無須連網。
- **Ollama**需要已啟動的本機服務與合適模型。模型下載必須明確操作，不會因開啟頁面或選擇模型自動開始。
- **OpenAI**需要可用 API Key 與額度。啟用遠端服務後，按下生成才傳送該次所需內容；請留意費用與作品隱私。

金鑰可在支援時保存在作業系統憑證庫，或只用於目前工作階段。不要把金鑰填進 `.env` 或提交至 Git。

## 翻譯

頂部 **翻譯**提供繁體中文與英文互譯。先在 **模型包安裝與完整性** 匯入含 `manifest.json` 與全部模型檔案的相容資料夾，確認來源、授權與用量後安裝。完整性驗證通過後，再選擇方向並翻譯。

單獨的清單不是完整模型包。權重不含在原始碼中，翻譯品質與速度依所裝模型及硬體而定。

## 備份與搬移

從 **設定與說明 → 設定與備份** 建立備份，保存備份檔及同名 manifest。還原前會驗證備份，並先備份目前資料庫。

更新或搬到另一台電腦前先建立備份。不要直接複製執行中的 SQLite 資料庫，也不要讓兩台電腦同時操作網路磁碟上的同一份資料庫。

故事、提示詞與生成紀錄可能包含完整私人原稿。請妥善保管備份；保存設定見 [生成紀錄與隱私](../CONTEXT_INSPECTION.md)。
